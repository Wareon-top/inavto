# INAVTO ASIA — стратегический план сайта

**Продукт:** автомобили из Китая и Южной Кореи (новые и с пробегом), доставка «под ключ» с растаможкой в любой город России.

**Цель документа:** зафиксировать стратегию создания современного, красивого и коммерчески эффективного сайта — от анализа конкурентов до дорожной карты разработки.

## 1. Анализ конкурента: kitaj-rulit.ru («Китай Рулит»)

### 1.1. Что делает конкурент

| Параметр | «Китай Рулит» |
|---|---|
| География закупки | Китай, Корея, Европа, ОАЭ |
| Типы авто | Новые и с пробегом, легковые + квадроциклы |
| Сроки доставки | 15–45 дней (заявленные), 30–60 по факту |
| Гарантии | Фиксация цены и сроков в договоре, страхование рисков на 1 год в страховых РФ |
| Соцдоказательства | 170+ доставленных авто, страница «Вручение авто» с фото передач ключей, отзывы на Яндекс.Картах |
| География присутствия | Представители в 20+ городах РФ (Москва, Казань, Новосибирск, Владивосток и др.) |
| Люди на месте | Представители-носители языка в Китае, Корее, ОАЭ |

### 1.2. Структура сайта конкурента

- **Главная** — оффер «Авто из Китая под заказ с доставкой под ключ», сроки, цены «от».
- **Каталог** (`/catalog`) — по брендам (Zeekr, Lixiang, GAC, BYD…), у каждого бренда своя страница-хаб.
- **Карточки моделей** — отдельные SEO-посадочные под каждую модель (`/zeekr-9x`, `/li-l6`, `/lil7-restailing`) с комплектациями и ценами.
- **Гео-страницы** (`/catalog/moskva`) — SEO-посадочные под запросы «авто из Китая + город».
- **Гарантии** (`/garantii`), **Доставка** (`/dostavka`), **О компании** (`/o-kompanii`).
- **«Вручение авто»** (`/vrychenie-avto`) — фотоотчёты передачи машин клиентам = главное соцдоказательство.
- **Блог** (`/blog`) — SEO-контент, обзоры моделей.

### 1.3. Сильные стороны конкурента (перенимаем)

1. **SEO-машина**: отдельная посадочная под каждую модель и под каждый город — это даёт органический трафик по тысячам низкочастотных запросов («zeekr 001 купить из китая», «авто из китая новосибирск»).
2. **Соцдоказательства через «вручения»**: фото/видео реальных передач ключей убедительнее текстовых отзывов.
3. **Прозрачность процесса**: клиенты в отзывах хвалят фото/видео-отчёты на каждом этапе перевозки — это снимает главный страх ниши («отдам деньги и пропадут»).
4. **Конкретика в гарантиях**: цена и срок фиксируются договором, страхование в российских СК.

### 1.4. Слабые стороны конкурента (наши точки роста)

1. **Устаревший шаблонный дизайн** — сайт выглядит как типовой лендинг-конструктор, без премиального ощущения. При среднем чеке 3–6 млн ₽ это диссонанс.
2. **Нет живого каталога** — карточки моделей статичны, нет фильтров, сортировки, актуальных цен с бирж.
3. **Нет калькулятора** — клиент не может сам прикинуть цену «под ключ» (растаможка, утильсбор, логистика). Это самый частый вопрос в нише.
4. **Нет личного кабинета / трекинга заказа** — статус машины узнают через менеджера.
5. **Корея — на вторых ролях**: у конкурента Корея упомянута, но не проработана. У INAVTO ASIA это половина позиционирования — можно занять нишу «Китай + Корея» целиком.
6. **Нет онлайн-подбора (квиза)** — нет механики захвата «холодного» трафика, который ещё не выбрал модель.

## 2. Позиционирование INAVTO ASIA

### 2.1. УТП (уникальное торговое предложение)

> **«Авто из Китая под ключ — с фиксированной ценой в договоре, онлайн-отслеживанием заказа и растаможкой в любой город России за 30–60 дней».**

Три кита позиционирования:

1. **Фокус на Китае.** Только новые автомобили с рынка Китая (электро, гибриды, бензин) — глубокая экспертиза по брендам, комплектациям и реальным ценам вместо «возим отовсюду».
2. **Прозрачность как продукт.** Калькулятор полной цены «под ключ» до заявки, личный кабинет с трекингом (выкуп → порт → таможня → СБКТС → выдача), фото/видео-отчёты на каждом этапе.
3. **Безопасность сделки.** Договор с фиксацией цены и сроков, оплата по инвойсу через банк (ВТБ), проверка авто перед выкупом, страхование груза.

### 2.2. Целевая аудитория

| Сегмент | Портрет | Что ему нужно от сайта |
|---|---|---|
| **Прагматик** (40% трафика) | 30–50 лет, хочет новый кроссовер/гибрид дешевле, чем у дилера РФ | Калькулятор, сравнение цены «здесь vs под заказ», гарантии |
| **Энтузиаст EV** (25%) | 25–40 лет, хочет Zeekr/Li Auto/BYD, разбирается сам | Актуальный каталог с комплектациями, обзоры, техподробности |
| **Семейный покупатель** (25%) | Хочет просторный 7-местный гибрид/кроссовер для семьи (Lixiang, Tank, Tiggo 8) | Подбор под задачу, безопасность сделки, объяснение простыми словами |
| **Перекуп/бизнес** (10%) | Возит партиями | Оптовые условия, скорость, прямой контакт |

├── Отзывы (Яндекс.Карты / Авито / VK виджеты)
├── Блог (обзоры моделей, изменения утильсбора, сравнения, гайды)

    ├── Трекинг: выкуплен → порт отправления → море/ж-д → таможня → СБКТС → выдача
    └── Документы и фотоотчёты по заказу

### 3.1. Ключевые страницы и их задачи

**Главная** (задача — за 5 секунд объяснить «что, откуда, почём, почему нам верить»):
1. Hero: оффер + строка поиска по каталогу + 2 CTA («Подобрать авто», «Рассчитать цену»).
2. Переключатель Китай / Корея с топ-моделями и ценами «под ключ от…».
3. Полоса доверия: N выданных авто, лет на рынке, офисы в Шанхае/Сеуле, договор, инвойс ВТБ.
4. Калькулятор (сокращённый) → полная версия.
5. Этапы работы (5–6 шагов с иконками и сроками).
6. Свежие вручения (фото + модель + город + срок доставки фактический).
7. Популярные модели (живые карточки из каталога).
8. FAQ (растаможка, утильсбор, гарантия, оплата) + блок захвата.

**Карточка модели** (задача — SEO-трафик + конверсия в заявку):
- Галерея (фото/видео), комплектации с ценами **в Китае** и **под ключ в РФ** — прозрачная разбивка: цена авто + логистика + таможня + утильсбор + комиссия.
- Кнопки: «Рассчитать точно», «Получить предложение в Telegram».
- Похожие модели, свежие вручения этой модели.

**Калькулятор** (задача — главный лид-магнит):
- Входные данные: страна, цена авто, объём/тип двигателя, мощность, возраст, физлицо/юрлицо.
- Выход: детальная смета под ключ + кнопка «Зафиксировать расчёт в заявке» (захват контакта).
- Формулы таможни/утильсбора должны обновляться из админки (ставки меняются).

**Квиз «Подбор авто»** (задача — конверсия холодного трафика):
- 4–5 шагов: бюджет → новый/б-у → тип кузова → сроки → контакт (Telegram/телефон).
- Результат приходит менеджеру в Telegram-бот (интеграция уже есть в backend).

## 4. Дизайн-концепция

### 4.1. Настроение

Премиальный автомобильный e-commerce, а не «лендинг растаможки». Ориентиры по ощущению: сайты Zeekr Global, Genesis, современных EV-брендов — много воздуха, крупная типографика, тёмная тема, автомобиль как герой кадра.

### 4.2. Визуальный язык

- **Палитра:** глубокий тёмный фон (#0F0F1A → #1A1A2E, уже в бренде), акцент — фирменный красный #C8102E (использовать дозированно: CTA, цены, статусы), нейтральные серые для текста, тонкие границы white/10.
- **Типографика:** гротеск с широкими жирными начертаниями для заголовков (Inter/Manrope/Unbounded для акцентов), табличные цифры для цен.
- **Фото:** только качественные рендеры/фото моделей на тёмном фоне; реальные фото вручений — в едином стиле обработки.
- **Микроанимации:** плавные появления при скролле, hover-эффекты карточек, анимированный трекер этапов доставки (визитная карточка сайта).
- **Иконография:** единый линейный набор (Lucide), никаких эмодзи в продакшн-версии (сейчас в MVP эмодзи — заменить).
- **Светлая тема** — опционально во 2-й фазе; тёмная — основная, она премиальнее и отличает от конкурента.

### 4.3. UX-принципы

1. Цена «под ключ» видна везде и сразу — никаких «цена по запросу».
2. Любая страница = максимум 1 клик до связи (плавающая кнопка Telegram/WhatsApp).
3. Mobile-first: 70%+ трафика ниши — мобильные.
4. Скорость: LCP < 2.5 c, изображения WebP/AVIF, ленивая загрузка каталога.

## 5. Функциональность и бизнес-механики

### 5.1. Конверсионная воронка

```
Трафик (SEO/контекст/Telegram/Авито)
  → Каталог / карточка модели / гео-страница
    → Калькулятор или Квиз            ← захват №1 (расчёт в обмен на контакт)
      → Заявка → Telegram-бот менеджеру ← захват №2
        → Договор → Личный кабинет + трекинг ← удержание и рефералы
          → Вручение → фотоотчёт на сайт + отзыв ← контент-цикл
```

### 5.2. Отличия от конкурента (наши фичи-дифференциаторы)

| Фича | У конкурента | У INAVTO ASIA |
|---|---|---|
| Живой каталог с фильтрами | ❌ статичные страницы | ✅ фильтры, сортировка, актуальные цены |
| Калькулятор под ключ | ❌ | ✅ детальная смета онлайн |
| Личный кабинет с трекингом | ❌ | ✅ статусы + фотоотчёты + документы |
| Корея как полноценное направление | частично | ✅ отдельный раздел + фид б/у |
| Квиз-подбор | ❌ | ✅ |
| Telegram-интеграция | частично | ✅ Mini App уже есть — сайт и MiniApp на одном API |

### 5.3. Админ-панель (для менеджеров)

- CRUD автомобилей/брендов/комплектаций, загрузка фото.
- Управление заявками (статусы, назначение менеджера).
- Обновление ставок таможни/утильсбора/курсов валют (¥, ₩, $).
- Публикация «вручений» и постов блога.
- Смена статусов заказа → авто-уведомление клиенту в Telegram.

## 6. Техническая стратегия

### 6.1. Что уже есть (MVP Telegram Mini App)

- Frontend: React 18 + Vite + Tailwind (тёмная тема, красный бренд) — страницы Home, Catalog, CarDetail, Calculator, Selection, Orders.
- Backend: Express + SQLite + Telegram-бот (заявки приходят в TG).
- Деплой: Railway.

### 6.2. Целевой стек сайта

| Слой | Выбор | Почему |
|---|---|---|
| Frontend | **Next.js 14+ (App Router) + Tailwind** | SSR/SSG обязателен для SEO (карточки моделей, гео-страницы) — SPA на Vite не годится для органики |
| UI | Tailwind + shadcn/ui + Framer Motion | скорость разработки + анимации |
| Backend | Существующий Express API, развитие; при росте — PostgreSQL вместо SQLite | переиспользуем код и бот |
| CMS/Админка | Своя лёгкая админка либо Strapi/Directus | менеджеры сами ведут каталог и блог |
| Интеграции | Telegram Bot API (есть), курсы ЦБ/крипто, Яндекс.Метрика + цели, CallTouch/коллтрекинг | |
| Деплой | Railway (есть) / Vercel для фронта | |

**Важно:** Telegram Mini App остаётся отдельным клиентом того же API — сайт и Mini App делят каталог, калькулятор и заявки. Это уникальная связка, которой нет у конкурента.

### 6.3. SEO-фундамент (закладывается с 1-го дня)

- SSR/SSG всех карточек моделей и брендов.
- Программные гео-страницы: `/kitay/{город}`, `/koreya/{город}` (по списку 30–50 городов).
- Schema.org: `Product` + `Offer` (цены), `AutoDealer`, `FAQPage`, `Review`.
- Блог 2–4 статьи/мес: обзоры моделей, «утильсбор 2026», сравнения («Zeekr 001 vs Li L6»).
- Карта сайта, ЧПУ-урлы, микроразметка хлебных крошек.

- A/B-тесты офферов и CTA, светлая тема.
- Контент-конвейер: каждое вручение → пост на сайт + соцсети.

## 9. Резюме: почему этот план выигрывает

1. **Копируем то, что у конкурента работает** (SEO-структура «модель+город», вручения как соцдоказательство, гарантии договором) — и делаем это технически лучше (SSR, микроразметка).
2. **Бьём в то, чего у него нет**: живой каталог, калькулятор, личный кабинет с трекингом, полноценная Корея, квиз, связка сайт + Telegram Mini App.
3. **Дизайн уровня бренда, а не лендинга** — при чеке 3–6 млн ₽ премиальный визуал напрямую влияет на доверие и конверсию.
4. **Переиспользуем готовое**: API, бот и бренд-стиль из MVP сокращают срок фазы 1 вдвое.
