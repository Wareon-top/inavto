## Регламент правок

1. Изменил каталог/тексты → `cd site && node build-pages.mjs`
2. Изменил видимые тексты → дополнить словари i18n (иначе новые строки останутся по-русски в 中文/EN)
3. Прогнать смоук в браузере: все страницы, 0 ошибок JS, квиз обе ветки, калькулятор
4. Коммит на логический блок, пуш в рабочую ветку
