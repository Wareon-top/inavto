# INAVTO ASIA — сайт (Фаза 1)

Маркетинговый сайт «Авто из Китая и Кореи под заказ» по стратегии из `docs/STRATEGY.md`.
Статический (HTML/CSS/JS, без сборки) — можно открыть локально или разместить на любом хостинге.

## Страницы

| Файл | Назначение |
|---|---|
| `index.html` | Главная: оффер, каталог-витрина, трекер, этапы, FAQ |
| `catalog.html` | Каталог новых авто из Китая с фильтрами (марка, кузов, двигатель, бюджет) |
| `korea.html` | Авто с пробегом из Кореи |
| `cars/<slug>.html` | Статические SEO-страницы всех моделей (24 шт., Schema.org Product+FAQ) |

| `car.html?slug=...` | Динамическая карточка (fallback, закрыта в robots.txt) |
| `calculator.html` | Калькулятор цены «под ключ» (пошлина, утильсбор, логистика, комиссия) |
| `kak-my-rabotaem.html` | Этапы заказа + трекер |
| `garantii.html` | Гарантии сделки |

## Как это устроено

- `css/style.css` — дизайн-система: светлая тема (фон #F5F5F7, белые карточки), акцент #C8102E, графит #1A1A2E для кнопок/футера, шрифты Manrope + Unbounded.
- `js/data.js` — каталог автомобилей и контакты (`INAVTO.CONTACTS` — **заменить на реальные телефон/Telegram/WhatsApp**).
- `js/main.js` — шапка/футер, квиз-подбор (попап), формы с маской телефона, фильтры, анимации.

## Генерация страниц моделей

После любого изменения каталога в `js/data.js`:

```bash
node build-pages.mjs   # пересоздаёт cars/*.html, sitemap.xml, robots.txt
```

Перед запуском замените `DOMAIN` в `build-pages.mjs` на реальный домен.

## Аналитика

Вставьте счётчик Яндекс.Метрики в `<head>` всех страниц и задайте
`window.INAVTO_YM_ID = XXXXXXXX` до подключения `main.js`. Цели уже
отправляются автоматически: `lead_submit`, `quiz_open`, `phone_click`,
`tg_click`, `wa_click`.

## Заявки

Все формы отправляют POST на `/api/selections` — это существующий backend из `backend/`
(заявка приходит менеджеру в Telegram-бот). Если сайт размещён на другом домене,
задайте адрес API до подключения `main.js`:

```html
<script>window.INAVTO_API = 'https://your-backend.example.com'</script>
```

Если API недоступен (чисто статический хостинг), форма всё равно покажет
подтверждение и предложит написать в Telegram.
