# Запуск сайта на VPS Sprintbox — инструкция для владельца

Что получится в итоге:
- **Сайт** — по адресу `http://<IP-сервера>/` (после покупки домена — `https://домен/`).
- **Админ-панель каталога** — `http://<IP-сервера>/admin`, вход по ключу.
- **Заявки с форм** — сохраняются в базу и прилетают в Telegram (когда добавим токен бота).

Всё занимает ~15 минут. Команды копируйте целиком и вставляйте в консоль сервера.

---

## Шаг 1. Создать бокс (сервер) в Sprintbox

В панели [cp.sprintbox.ru](https://cp.sprintbox.ru) создайте новый бокс:

- **Операционная система: Ubuntu 24.04** (подойдёт и 22.04, и Debian 12).
- **Тариф**: достаточно самого простого с **1 ГБ памяти** и 10 ГБ диска — с запасом.

После создания в карточке бокса появятся **IP-адрес** и **пароль root** — они понадобятся дальше.

## Шаг 2. Открыть консоль сервера

Любой из способов:

- **Веб-консоль в панели Sprintbox** — если в карточке бокса есть кнопка консоли, самый простой путь.
- **С компьютера**: Windows — откройте PowerShell, Mac — Терминал, и введите:
  ```
  ssh root@ВАШ_IP
  ```
  На вопрос про fingerprint ответьте `yes`, затем вставьте пароль root
  (при вводе пароль не отображается — это нормально).

## Шаг 3. Создать токен GitHub (одноразовый «пароль» для скачивания кода)

Код сайта лежит в закрытом репозитории GitHub, серверу нужен доступ на чтение:

1. Зайдите на [github.com](https://github.com) под аккаунтом **wareon-top**.
2. Аватар справа вверху → **Settings**.
3. В самом низу слева → **Developer settings**.
4. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
5. Заполните:
   - Token name: `inavto-server`
   - Expiration: **90 days** (или больше через Custom)
   - Repository access: **Only select repositories** → выберите **inavto**
   - Permissions → Repository permissions → **Contents** → **Read-only**
6. Кнопка **Generate token** → скопируйте строку вида `github_pat_…` — она показывается один раз.

## Шаг 4. Скачать код на сервер

Вставьте в консоль (сначала **замените слово `GITHUB_TOKEN`** на ваш токен из шага 3):

```bash
apt-get update && apt-get install -y git
git clone -b claude/new-session-2ptdl6 https://oauth2:GITHUB_TOKEN@github.com/wareon-top/inavto.git /opt/inavto
```

## Шаг 5. Запустить установку

```bash
bash /opt/inavto/deploy/install.sh
```

Скрипт всё ставит сам и задаст 2–3 вопроса:

1. **Ключ админ-панели** — вставьте ключ, который прислал разработчик (или Enter — сгенерируется новый, скрипт его покажет).
2. **Токен Telegram-бота** — если пока нет, просто Enter (добавим позже).
3. **Telegram ID** (только если ввели токен) — куда слать заявки; свой ID узнаётся у бота **@userinfobot**.

В конце скрипт напишет `ГОТОВО!` и адреса сайта и админки.

## Шаг 6. Проверить

1. Откройте `http://ВАШ_IP/` — сайт работает.
2. Откройте `http://ВАШ_IP/admin` → введите ключ админки.
3. Нажмите **«Импортировать 16 моделей сайта»** — каталог наполнится стартовыми моделями.

Готово. Теперь машины добавляются и редактируются прямо в админке, без программиста.

---

## Как обновлять сайт (после правок в коде)

Одна команда в консоли сервера:

```bash
bash /opt/inavto/deploy/update.sh
```

## Подключить Telegram-заявки позже

1. В @BotFather: **отзовите старый токен** (`/mybots` → бот → API Token → Revoke) — старый был скомпрометирован — и получите новый.
2. Узнайте свой ID у @userinfobot.
3. В консоли сервера (замените значения):
   ```bash
   echo "BOT_TOKEN=НОВЫЙ_ТОКЕН_БОТА" >> /etc/inavto.env
   echo "ADMIN_CHAT_ID=ВАШ_TELEGRAM_ID" >> /etc/inavto.env
   systemctl restart inavto
   ```

## Когда появится домен

1. У регистратора домена создайте **A-запись** на IP сервера (`@` → IP и `www` → IP).
2. Скажите разработчику — он пропишет домен в SEO-разметке сайта.
3. Включите HTTPS (бесплатный сертификат Let's Encrypt):
   ```bash
   apt-get install -y certbot python3-certbot-nginx
   sed -i 's/server_name _;/server_name ВАШ_ДОМЕН www.ВАШ_ДОМЕН;/' /etc/nginx/sites-available/inavto
   nginx -t && systemctl reload nginx
   certbot --nginx -d ВАШ_ДОМЕН -d www.ВАШ_ДОМЕН
   ```

## Если что-то пошло не так / частые вопросы

| Вопрос | Команда |
|---|---|
| Забыли ключ админки | `grep ADMIN_TOKEN /etc/inavto.env` |
| Сменить ключ админки | `sed -i 's/^ADMIN_TOKEN=.*/ADMIN_TOKEN=НОВЫЙ_КЛЮЧ/' /etc/inavto.env && systemctl restart inavto` |
| Посмотреть логи бэкенда | `journalctl -u inavto -n 50` |
| Перезапустить бэкенд | `systemctl restart inavto` |
| Сервер перезагрузился | Ничего делать не нужно — всё поднимется само |
| Истёк токен GitHub (update.sh ругается) | Создайте новый токен (шаг 3) и выполните: `git -C /opt/inavto remote set-url origin https://oauth2:НОВЫЙ_ТОКЕН@github.com/wareon-top/inavto.git` |

**Безопасность**: ключ админки и токены — как пароли: не публикуйте их и не отправляйте в общие чаты. База данных и фото лежат в `/var/lib/inavto` и переживают любые обновления кода.
