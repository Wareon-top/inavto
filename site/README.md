# INAVTO ASIA — сайт

Маркетинговый сайт «Авто из Китая под заказ с доставкой под ключ в Россию».
Статический (чистые HTML/CSS/JS, без сборки) — можно открыть локально или разместить на любом хостинге.

> Продукт — **только Китай**. Корея из данных, страниц, текстов и генератора удалена и не возвращается.

## Дизайн-система (v3 «Monochrome Editorial»)

- `css/style.css` — премиальный минимализм: бумага `#FAFAFA` (фон), чернила `#050505` (текст, линии, кнопки), `border-radius: 0`, линии 1px, бенто-сетки через `gap:1px`.
- Типографика: **Unbounded** (display, UPPERCASE-заголовки) + **Inter** (текст). У `.h1 .accent` — прозрачная заливка с обводкой.
- Кастомный курсор-точка, инверсия кнопок при ховере, параллакс hero-фото, reveal-анимации, `prefers-reduced-motion` уважается.
- `js/data.js` — каталог (16 моделей) и контакты (`INAVTO.CONTACTS` — **заменить на реальные телефон/Telegram/WhatsApp/почту**).
- `js/main.js` — инжект шапки/футера/квиза/мобильного CTA-бара на все страницы, ветвящийся квиз, формы с маской телефона, аналитика, курсор, параллакс.

## Генерация SEO-страниц

После любого изменения каталога в `js/data.js`:

```bash
node build-pages.mjs   # пересоздаёт cars/*.html, sitemap.xml, robots.txt
```

Перед публикацией замените `DOMAIN` в `build-pages.mjs` на реальный домен.

## Аналитика

Вставьте счётчик Яндекс.Метрики в `<head>` всех страниц и задайте
`window.INAVTO_YM_ID = XXXXXXXX` до подключения `main.js`. Цели отправляются
автоматически через `INAVTO.goal(...)`: `lead_submit`, `quiz_open`,
`quiz_step_N`, `calc_used`, `phone_click`, `tg_click`, `wa_click`, `form_abandon`.

## Заявки

Все формы отправляют POST на `/api/selections` — существующий backend из `backend/`
(заявка приходит менеджеру в Telegram-бот). Если сайт на другом домене,
задайте адрес API до подключения `main.js`:

```html
<script>window.INAVTO_API = 'https://your-backend.example.com'</script>
```

Если API недоступен (чисто статический хостинг), форма всё равно покажет
подтверждение и предложит написать в Telegram.
